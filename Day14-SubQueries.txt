What is Subquery :

--> A subquery is a query inside another query
--> It is written inside parenthesis() and its result is used by the outer query
--> It is also called as inner query, nested query, inner select

General Syntax:

Select column-list
from table
where column operator(select column from table where condition);

Purpose Of Subquery 

--> To breakdown complex problems into smaller queries
--> To use result of one query as input to another
--> To avoid multiple steps(Write in a single query instead of temp tables)

Types of SubQueries

-->Single row subquery
-->Multi-row subquery
-->Nested  subquery
-->Corelated subquery
-->Exists/Non-exists subquery

1.Single row subquery:

--> Single row subquery returns exactly one row and one column 
--> They use comparision operators like <,>,<=,>=

Characteristics :

--> Returns only one value
-->Can use single value comparision operators
-->If subquery returns no rows or multiple rows it causes an error

Syntax:

select columns
from table
where column operator(select column from table where condition);

2.Multi-row subquery

(2)(1) Multi-row subquery(in)

-->A multi-row subquery returns more than one row
-->The in operator is used return when you want to compare a value with multiple values returned by the subquery

Characteristics :

--> Returns multiple rows
--> Uses in operator
--> Check weather a value exists in the list returned by the subquery
--> Equivalent to multiple or conditions
--> Most commonly used for matching values

Syntax :

Select Columns from table
where column IN(select column from table where condition);

(2)(2) Multi-row subquery(ANY/Some)
--> Multi-row subquery returns multiple rows using any/some
--> The condition is true if it matches atleast one value returned by the subquery 

Characteristics :

--> Returns multiple values
-->Any and some are interchangabale
--> Condition is true if any of the value stisfy the condition
--> After used with IN,>ANY,<ANY,=ANY..ETC

Syntax :

Select Columns from table
where column ANY/SOME(select column from table where condition);

(2)(3) Multi-row subquery(ALL) :

--> The ALL operator means the condition must be true for all values return by the subquery

Characteristics :

--> Condition must be true for all values in the subquery result
--> Often userd with>ALL,<ALL,=ALL,<=ALL
--> >ALL means greater than the max value
--> <All means less than the minimum values 

Syntax :

Select Columns from table
where column ALL(select column from table where condition);

3.Nested subquery

-->Nested subquery are subqueries with subqueries
--> They can be multiple level deep and are executed from the innermost to te outermost 

Characteristics :

--> Multiple levels of nesting
-->Inner queries execute first
-->Can combine different types of subqueries
-->Useful for complex conditions

Syntax :

Select Column_list 
 from table
where column =(Select Columns from table where column=(SELECT COLUMN FROM TABLE WHERE CONDITION);

4.Corelated subquery

Corelated subquery are subqueries that referenece column from the outer query
-->Unlike regular subqueries that excute once,corelated subqueries executes once from each row proceesed by the outer query 

Characteristics :

-->Reference column from the outer grey
-->Executes multiple times(once per outer row)
-->Cannot be executed independently
-->Often used with EXISTS,NON-EXISTS
-- Genneraly slower than non-corelated subquery

Syntax:

select columns
from table1 outer alias
where condition(select column
                 from table2 inner_allias
                 where inner_allias.column=outer_allias.column);


Exists/NoT-exists subquery

-->Exists is used to test whether a subquery returns any rows
-->It returns true if the subquery returns at least one row .False otherwise
-->NOT EXISTS returns true if the subquery returns no rows

Characteristics :

-->Returns TRUE/FALE(BOOLEAN RESULT)
-->More efficient than in large datasets
-->Often used with corellated subqueries
-->Stoops execution as soon as first match found
-->.Select clause is EXISTS doesn't matter (Often Select 1)

Syntax 

select columns
from table1
where exists(Select1 from table2 where condition)

select columns
from table1
where NOT exists(Select1 from table2 where condition)

CREATE TABLE country (
    Code            VARCHAR(3) PRIMARY KEY,
    Name            VARCHAR(100) NOT NULL,
    Continent       VARCHAR(30)  NOT NULL,
    Region          VARCHAR(50)  NOT NULL,
    Population      BIGINT       NOT NULL,
    LifeExpectancy  DECIMAL(4,1),
    GNP             DECIMAL(15,2),
    Capital         INT
);

CREATE TABLE city (
    ID           INT PRIMARY KEY AUTO_INCREMENT,
    Name         VARCHAR(100) NOT NULL,
    CountryCode  VARCHAR(3)   NOT NULL,
    District     VARCHAR(50),
    Population   BIGINT       NOT NULL
);

CREATE TABLE countrylanguage (
    CountryCode  VARCHAR(3)  NOT NULL,
    Language     VARCHAR(50) NOT NULL,
    IsOfficial   ENUM('T','F') NOT NULL,
    Percentage   DECIMAL(4,1)
);

-- Department Table
CREATE TABLE Department (
    dept_id INT PRIMARY KEY,
    dept_name VARCHAR(50),
    location VARCHAR(50)
);

-- Employee Table
CREATE TABLE Employee (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(50),
    salary DECIMAL(10,2),
    dept_id INT,
    job VARCHAR(50),
    hire_date DATE,
    FOREIGN KEY (dept_id) REFERENCES Department(dept_id)
);

-- Project Table
CREATE TABLE Project (
    proj_id INT PRIMARY KEY,
    proj_name VARCHAR(50),
    dept_id INT,
    budget DECIMAL(12,2),
    FOREIGN KEY (dept_id) REFERENCES Department(dept_id)
);
