Stored Procedures
------------------------------------------

A stored Procedure is a named,pre-compiled collection of one or more SQL statements i.e is stored inside the database and can be executed(called) whenever required.Instead of sending a long block of sql code from an application everytime,the application simply calls the procedure by name

Why to use stored Procedures :

1.Performance: Pre-compiled and cached by the database engine,so repeated execution is faster than sending raw SQL each time
2.Reusability:Write the logic once,call it from many applications or scripts
3.Security:Users Can granted execute permisiion on a procedure without granting direct access to the underlying tables
4.Reduced Network Traffic:A single call statement replaces many lines of SQL sent over the network
5.Maintainability:Business logic is centralized in the databse,so changes are made in one place
6.Consistency:Ensures the same validation/business rules are applied everytime,regardlesss of which application calls itsrtions,Conditions,Loops..etc


CREATE PROCEDURE SYNTAX :

DELIMITER // 
CREATE PROCEDURE PROCEDURE_NAME(
                [IN|OUT|INOUT] Parameter_name data types,.....
)
BEGIN
    -----------SQL statements/Logic
    -----------Declarations,conditions,loops..etc
END //
DELIMITER;

ADVANTGES:

-->Faster execution after completion
-->Reduced duplicate SQL
-->Support Transactions,loops,conditions,variables,cursors and exceptional handlers

DISADVANTAGES :

--> Debugging can be difficult
--> Vendor specific Syntax
-->Complex procedures may become hard to maintain

1. IN PARAMETER

-------------------------------------------OUT PARAMETER------------------------------------------

OUT PARAMETER : An OUT PARAMETER  is used to return a value from the stored procedure to the caller .The caller provides a variable to receive the result

Syntax :

CREATE PROCEDURE procedure_name(OUT paramter_name datatype)
BEGIN
set paramter_name=value;
END;

SHOW PROCEDURE STATUS WHERE Db=companydb;

DELIMITER //
mysql>  CREATE PROCEDURE total_employees(OUT total INT)
    -> BEGIN
    ->   SELECT COUNT(*) INTO TOTAL FROM employees;
    -> END //
Query OK, 0 rows affected (0.04 sec)

mysql> DELIMITER ;
mysql> SET @total=0;
Query OK, 0 rows affected (0.03 sec)

mysql> CALL total_employees(@total);
Query OK, 1 row affected (0.04 sec)

mysql> SELECT @total;

+--------+
|     10 |
+--------+

DELIMITER //
CREATE PROCEDURE EMPLOYEE_SALARY(IN EID INT,OUT EMP_SAL DECIMAL(10,2))
BEGIN
SELECT SALARY INTO EMP_SAL FROM employees WHERE EMP_ID=EID;
END //

DELIMITER ;
SET @EMP_SAL=0;

CALL EMPLOYEE_SALARY(105,@EMP_SAL);

SELECT @EMP_SAL;
